3.1Hướng dẫn sử dụng Luna

Luna là AI Agent của phòng Mua hàng XNK chạy trên Microsoft Teams: hiểu câu hỏi tiếng Việt, chọn đúng lệnh trong thư viện, truy vấn trực tiếp dataset Power BI BCQTMH và trả lời bằng bảng số kiểm chứng được.

Bắt đầu

  • Trên Microsoft Teams, mở ứng dụng Luna (Ứng dụng → tìm "Luna") để chat riêng 1–1, hoặc thêm Luna vào nhóm chat / kênh.
  • Trong nhóm phải tag @Luna thì Luna mới trả lời; câu trả lời sẽ tag lại người hỏi và trích tin nhắn gốc.
  • Nhóm có người không được xem giá mua: Luna gửi câu trả lời riêng cho người hỏi, trong nhóm chỉ báo "đã gửi riêng".

Hai cách hỏi

  • Gõ lệnh bắt đầu bằng dấu /, ví dụ /kpi 10/2026, /giao-hang foton 2026 theo-thang, /top-ma mobis 200. Gõ /lenh để xem nhóm lệnh ngay trong chat.
  • Hỏi bình thường, ví dụ "leadtime hàng air tháng 9 có đạt không?" – Luna tự chọn lệnh phù hợp.
  • Mỗi câu hỏi được xử lý độc lập, Luna không nhớ câu trước: hãy nêu đủ NCC, kỳ, loại hàng trong cùng một câu.
  • Không nêu kỳ thì lấy tháng hiện tại; không nêu bộ lọc thì lấy "Tất cả". Cuối câu trả lời luôn ghi bộ lọc đã áp dụng.

Đọc câu trả lời

  • Bảng chỉ có số, định dạng giống Bravo (1,234,567.89), đơn vị ghi ở tiêu đề cột – copy dán thẳng sang Excel.
  • Câu trả lời quá dài (bảng trên 60 dòng): Luna gửi tóm tắt + 10 dòng đầu và link file Excel tạm; file bị xoá khi hết ngày, cần giữ thì tải về.
  • Số liệu lấy từ báo cáo Power BI BCQTMH đã publish (làm mới 07:00 và 12:30 hằng ngày). Nếu lần làm mới gần nhất lỗi hoặc quá 26 giờ, Luna không trả số và báo lý do.
  • Bạn chưa có quyền dùng một lệnh thì Luna báo "không có quyền" – liên hệ chủ hệ thống để được cấp.

Việc Luna làm tự động

  • Bảng tin công việc gửi vào nhóm phòng lúc 9:00 thứ 2 – thứ 6.
  • Tra danh bạ công cụ: /tool, /template, /danh-ba.
  • Gõ /so-tay để Luna gửi link sổ tay này.

Gặp câu trả lời sai hoặc câu hỏi Luna chưa hiểu: chụp màn hình gửi Lê Quỳnh Giao để bổ sung lệnh.

4.1TOOL-ADM-01 – Điền khảo sát phối hợp TST

Nguồn: tools/TOOL-ADM-01_khao-sat-tst/phat-hanh/README.md

Hỗ trợ nhân viên MH-XNK điền khảo sát phối hợp phòng ban trên Edge theo danh sách trong bảng. Có lịch sử để tránh gửi trùng.

Cách mở

Bấm đúp file Auto_Khao_Sat_TST.exe trong thư mục này. Máy cần có trình duyệt Microsoft Edge.

Các bước dùng

  1. Chọn tháng/năm khảo sát và các tuỳ chọn ở phía trên (Bình quân ±1, Tự động gửi; mặc định Tự động gửi đang tắt).
  2. Ở tab Danh sách phiếu, nhập từng dòng hoặc bấm Dán Excel để dán nhiều dòng. Cột Mã nhân viên là bắt buộc (nên để định dạng Text trong Excel để giữ số 0 ở đầu).
  3. Có thể bấm Danh bạ nhân viên, chọn một người rồi bấm Điền vào dòng đang chọn để điền sẵn mã, họ tên, email.
  4. Bấm Bắt đầu. Tool mở Edge và điền lần lượt từng dòng; muốn ngừng thì bấm Dừng.
  5. Đọc cột Trạng thái của từng dòng để biết dòng nào đã điền/đã gửi, dòng nào lỗi hoặc bị chặn.
  6. Xong việc, bấm Đóng các tab đã điền để đóng các tab Edge còn mở.

Kết quả lưu ở đâu

Tool điền thẳng lên trang khảo sát. Lịch sử từng phiếu xem bằng nút Xem lịch sử; bảng đang nhập được tự lưu cho lần mở sau.

Lưu ý

  • Không đổi link hoặc điểm để gửi lại cùng một người trong cùng kỳ: tool sẽ chặn gửi trùng.
  • Nếu kết quả gửi chưa rõ, tool dừng cả lô: không xoá lịch sử để thử lại, hãy báo người phụ trách kiểm tra.
  • Nhật ký: bấm nút Mở log hoặc xem thư mục %LOCALAPPDATA%\TST\TOOL-ADM-01\logs\.

Cần hỗ trợ: xem mục Hỗ trợ.

4.2TOOL-ADM-02 – In hàng loạt

Nguồn: tools/TOOL-ADM-02_in-hang-loat/phat-hanh/README.md

In hàng loạt các file Excel, Word, PDF trong một thư mục. Ngoài ra có chức năng ghép trang đầu các tờ khai ToKhaiHQ7N thành một file PDF.

Cách mở

Bấm đúp file Tool_In_Hang_Loat.exe trong thư mục này. Máy cần có máy in; in Excel/Word cần cài Microsoft Excel/Word.

Các bước dùng

  1. Chọn file hoặc thư mục cần in, xem danh sách (OK/LỖI) và các tab xem trước/kiểm tra.
  2. Chọn chế độ In hàng loạt (Excel in sheet đầu, Word, PDF) hoặc Trang đầu TKHQ (Excel tờ khai có tên chứa ToKhaiHQ7N).
  3. Bấm Nạp máy in, chọn máy in, số bản, in 1 hay 2 mặt, khổ giấy. Với chế độ trang đầu tờ khai có thể chọn lưu thành file PDF.
  4. Bấm Chạy / In và xác nhận các hộp thoại hiện ra.
  5. Theo dõi tiến độ; khi xong dùng nút mở kết quả hoặc mở thư mục nếu có.

Kết quả lưu ở đâu

In trực tiếp ra máy in thì không tạo file. Với ghép trang đầu tờ khai, bạn chọn nơi lưu file PDF ngay khi chạy.

Lưu ý

  • PDF được gửi sang máy in qua ứng dụng PDF mặc định; tool báo đã gửi lệnh in, không xác nhận giấy đã in ra.
  • Nếu gặp lỗi, đóng các file Excel/Word đang mở rồi chạy lại.
  • Nhật ký: bấm nút Mở log hoặc xem thư mục %LOCALAPPDATA%\TST\TOOL-ADM-02\logs\.

Cần hỗ trợ: xem mục Hỗ trợ.

4.3TOOL-ADM-03 – In đề xuất Base Request

Nguồn: tools/TOOL-ADM-03_in-de-xuat-base/phat-hanh/README.md

Đọc danh sách mã đề xuất trong file Excel, kiểm tra đề xuất đã được duyệt xong chưa trên Base Request, tải và in file chữ ký điện tử, rồi ghi kết quả vào Excel.

Cách mở

Bấm đúp file Tool_Print_Base_Request.exe trong thư mục này. Máy cần có trình duyệt Chrome và máy in; bạn cần có tài khoản Base Request.

Các bước dùng

  1. Chuẩn bị file List.xlsx chứa danh sách Mã đề xuất; chọn đúng file này trong tool.
  2. Chọn máy in ở mục Máy in chỉ định (hoặc dùng máy in mặc định của Windows).
  3. Lần đầu: bấm Mở Chrome & Đăng nhập Base, đăng nhập tài khoản Base trên cửa sổ Chrome vừa mở. Các lần sau không cần đăng nhập lại.
  4. Bấm BẮT ĐẦU CHẠY TOOL. Tool lần lượt mở từng đề xuất, kiểm tra duyệt, tải và in file chữ ký điện tử.

Kết quả lưu ở đâu

  • File PDF chữ ký điện tử tải về thư mục downloads cạnh tool.
  • Trạng thái từng dòng ghi ngay vào List.xlsx: Đã in, Chưa duyệt hết hoặc Lỗi.

Lưu ý

  • Đề xuất ở trạng thái Chưa duyệt hết sẽ không được in; chờ duyệt xong rồi chạy lại.
  • Nếu ghi Excel bị lỗi, đóng file List.xlsx đang mở rồi chạy lại.
  • Dòng Lỗi: kiểm tra lại mã đề xuất hoặc kết nối mạng rồi chạy lại.

Cần hỗ trợ: xem mục Hỗ trợ.

4.4TOOL-ADM-04 – Ký PDF hàng loạt

Nguồn: tools/TOOL-ADM-04_ky-pdf-hang-loat/phat-hanh/README.md

Ký số nhiều file PDF một lần bằng chứng thư số của công ty. Hình chữ ký giống bản cũ: bên trái là tên công ty, bên phải là "Digitally signed by…", DN và ngày giờ ký. File gốc giữ nguyên, file đã ký lưu sang thư mục riêng.

Cách mở

Bấm đúp file bulk_pdf_signer.exe trong thư mục này. Máy cần cài phần mềm USB token (NCA Token Manager của NewtelCA) và cắm token trước khi ký.

Các bước dùng

  1. Bấm Chọn file hoặc Chọn thư mục để chọn các file PDF cần ký.
  2. Chọn vị trí chữ ký (9 ô: Trên / Giữa / Dưới × Trái / Giữa / Phải), lề (pt, mặc định 20) và trang ký (trang đầu, trang cuối, tất cả trang hoặc một trang số). Xem tab Xem trước để thấy ô chữ ký nằm ở đâu.
  3. Chọn nguồn chứng thư: USB token (mặc định) hoặc file PFX.
  4. Kiểm tra thư mục kết quả (mặc định thư mục Da_ky cạnh file gốc).
  5. Bấm Ký số, nhập PIN token (hoặc mật khẩu PFX). Tool hiện thông tin chứng thư rồi ký lần lượt từng file.
  6. Xem danh sách OK/LỖI và tab Kiểm tra. Bấm Mở thư mục để lấy file đã ký.

Kết quả lưu ở đâu

Trong thư mục kết quả đã chọn, cùng tên với file gốc. File gốc không bị sửa.

Lưu ý
